# Стимулы и анализ движений глаз

Единый веб-продукт для исследований с айтрекером: шесть методик, для каждой — генератор стимулов (готов) и модуль анализа движений глаз (в разработке).
Всё работает в браузере, без сервера. Дизайн и алгоритмы салиентности — из модуля «Салиентность».

Методики: эмоционально окрашенные изображения; поиск эмоционально окрашенных слов; плоскостное ментальное вращение; вербальное мышление (филворд); определение различий; траектории.

```
index.html            главная: для каждой методики две плитки («Создание стимулов», «Анализ движений глаз»)
css/                  тема и оформление
js/app.js, help.js    навигация и справка (в т. ч. методология анализа: help-analysis.js)
js/analysis.js        разделы анализа (в разработке)
js/common/            генератор с seed, CSV, ZIP, инструкции PNG, интерфейс
js/core/              статистика, салиентность, метрики
js/kit/               общие блоки интерфейса и архива (поля, результаты, Word-документ «Методы»)
js/modules/<методика>/  generator.js (логика без DOM), render.js (PNG), ui.js
tests/ tools/ docs/ data/
```

Запуск: `npm start` → http://localhost:8765/ (ES-модули требуют HTTP-сервер). Тесты: `npm test`.

## Общие правила
- Ответы участника — мышью; после ответа и для старта — ПРОБЕЛ (вписано в инструкции по умолчанию).
- Цвета по умолчанию: фон `#ebebeb`, объекты и шрифт `#000000`; рядом с выбором показан код цвета.
- В архив всегда входят: стимулы PNG, инструкции PNG, таблицы (стимулы, зоны интереса, салиентность, яркость, оценки), `settings.json`, `README.txt`; по галочкам — `methods_description.docx` (Word, описание для раздела «Методы») и `answer_key.csv`.
- Яркость стимула: относительная яркость Rec. 709 по sRGB, шкала 0–1.
- Номер случайного набора + настройки полностью воспроизводят набор стимулов.

Документы: `docs/protocol_participant_data.docx` (протокол для экспериментатора), `docs/handoff-cognitive-and-interview.md`.
