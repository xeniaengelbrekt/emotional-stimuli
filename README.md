# Эмоциональные стимулы и когнитивные стимулы — генераторы и анализ

Веб-приложение (дизайн и алгоритмы — из модуля [«Салиентность»](https://github.com/xeniaengelbrekt/saliency-tool)),
работает целиком в браузере, без сервера.

| Модуль | Статус |
|---|---|
| Изображения · создание стимулов (сетка 2×2) | готов |
| Изображения · анализ движений глаз | в разработке |
| Слова · создание стимулов («найдите слово») | готов |
| Слова · анализ движений глаз | в разработке |

## Запуск

ES-модули требуют HTTP-сервер: `npm start` (или `python3 -m http.server 8765`) → http://localhost:8765/.
Подходит и GitHub Pages. Тесты логики: `npm test`.

## Изображения

Вход: изображения + CSV со средними оценками (файл, группа, нейтральность, позитивность, грусть, угроза, реалистичность).
Категория — шкала с максимальной оценкой. Салиентность — FT (Lab, цветные сцены) по умолчанию; метрики mean, entropy, center bias, spread %.

* **Контрольные**: 4 изображения одной категории и группы — по 1 на категорию в каждой группе (16).
* **Экспериментальные**: 4 разные категории одной группы — по 4 на группу (16); положения категорий выравниваются по всему набору, раскладки не повторяются.
* Размер по умолчанию 1920×1080; число стимулов и повторы настраиваются. Если без повторов не хватает изображений — предупреждение.

## Слова

Вход: CSV (слово, 4 шкалы, частотность). Уровни 20/30/40 слов (настраиваются).

* **Контрольные**: все слова одной категории — по 1 на категорию на уровень (12).
* **Экспериментальные**: дистракторы из других категорий поровну (или из всех четырёх — настройка), по 1 на категорию целевых слов на уровень (12).
* Целевые слова категорий уравниваются по длине и частотности, дистракторы подбираются близко к целевому; положение цели выравнивается по ячейкам и зонам экрана.

## Архив

`stimuli/*.png` (имена из характеристик, напр. `img_exp_animals_02_TL-pos_TR-thr_BL-neu_BR-sad`, `word_exp_30w_target-threat_01`),
`stimuli.csv`, `stimuli_tiles.csv` / `stimuli_words.csv` (категории, оценки, метрики, зоны интереса в пикселях), `settings.json` (с seed).

## Допущения

* Группа изображения берётся из CSV, из начала имени файла (`animals_03.jpg`) или назначается вручную.
* В экспериментальных словесных стимулах по умолчанию дистракторы — только из категорий, отличных от категории целевого слова.

# Когнитивные стимулы (`cognitive/`)

Отдельное веб-приложение в том же оформлении: `http://localhost:8765/cognitive/` (`npm start`).
Все стимулы — PNG, по умолчанию 1920×1080 (размер настраивается); у каждого уникальное английское имя из характеристик;
готовые стимулы можно просмотреть и скачать архивом (PNG + инструкции + таблицы + `settings.json`).

| Модуль | Статус |
|---|---|
| Плоскостное ментальное вращение | готов |
| Вербальное мышление (филворд) | готов |
| Определение различий | готов |
| Траектории (по мотивам теста Кинга — Дэвика) | готов |
| Анализ движений глаз и ответов | в разработке |

## Плоскостное ментальное вращение

Воспроизводит презентацию автора: поле 10×10, 10 закрашенных клеток в шести «фигурках» (линии 3, 2, 2, 1, 1, 1; не касаются друг друга,
крайний ряд пуст), сверху фигура-задание, ниже четыре варианта 1–4. Задания: поворот на 90° по часовой, на 90° против часовой,
зеркально, на 180°. Варианты — те же клетки после четырёх преобразований (см. `cognitive/js/rotation/generator.js`).
Цветность (можно несколько): ч/б, каждый квадратик своего цвета, каждая фигурка своего цвета (цвета равной светлоты в OKLCH).
Салиентность считается для каждого стимула и для каждой области (задание, верный и неверные варианты).

## Вербальное мышление (филворд)

Целевые слова из CSV (формат как в генераторе слов). Сетка 10×10 по умолчанию, ч/б или цветная, дистракторы — буквы или буквы и цифры,
горизонталь / вертикаль / обе. По умолчанию по одному стимулу на каждую эмоциональную категорию для каждого направления; слова
разных категорий подбираются близкими по длине, частотности и оценке; положение слов выравнивается по 9 зонам сетки.

## Определение различий

Серия экранов: запомнить N объектов, затем на каждом экране один объект меняется. По умолчанию 6 экранов в серии,
серии на 4, 6, 8, 10 объектов, расположение по сетке, объекты — буквы (или числа в заданном диапазоне).

## Траектории

Числа 1…N в несколько строк (по умолчанию 15 в 3 строки): прослеживать по возрастанию / убыванию (меняется только инструкция),
расположение по прямой / по зигзагу, расстояния фиксированные / разные, дистракторы (число другого цвета, буква, квадрат, треугольник),
которые заменяют число. Общие настройки порождают таблицу стимулов; каждый стимул можно настроить отдельно, а значение столбца —
применить ко всем.

## Тесты

`npm test` — в том числе `tests/test-cognitive.mjs` (геометрия фигур и вариантов ответа, размещение слов, серии различий, раскладка траекторий).
