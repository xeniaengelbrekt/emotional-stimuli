# Эмоциональные стимулы — генератор и анализ

Веб-приложение (дизайн и алгоритмы — из модуля [«Салиентность»](https://github.com/xeniaengelbrekt/saliency-tool)),
работает целиком в браузере, без сервера.

| Модуль | Статус |
|---|---|
| Изображения · создание стимулов (сетка 2×2) | готов |
| Изображения · анализ движений глаз | в разработке |
| Слова · создание стимулов («найдите слово») | готов |
| Слова · анализ движений глаз | в разработке |

## Запуск

ES-модули требуют HTTP-сервер: `npm start` (или `python3 -m http.server 8765`) → http://localhost:8765/.
Подходит и GitHub Pages. Тесты логики: `npm test`.

## Изображения

Вход: изображения + CSV со средними оценками (файл, группа, нейтральность, позитивность, грусть, угроза, реалистичность).
Категория — шкала с максимальной оценкой. Салиентность — FT (Lab, цветные сцены) по умолчанию; метрики mean, entropy, center bias, spread %.

* **Контрольные**: 4 изображения одной категории и группы — по 1 на категорию в каждой группе (16).
* **Экспериментальные**: 4 разные категории одной группы — по 4 на группу (16); положения категорий выравниваются по всему набору, раскладки не повторяются.
* Размер по умолчанию 1920×1080; число стимулов и повторы настраиваются. Если без повторов не хватает изображений — предупреждение.

## Слова

Вход: CSV (слово, 4 шкалы, частотность). Уровни 20/30/40 слов (настраиваются).

* **Контрольные**: все слова одной категории — по 1 на категорию на уровень (12).
* **Экспериментальные**: дистракторы из других категорий поровну (или из всех четырёх — настройка), по 1 на категорию целевых слов на уровень (12).
* Целевые слова категорий уравниваются по длине и частотности, дистракторы подбираются близко к целевому; положение цели выравнивается по ячейкам и зонам экрана.

## Архив

`stimuli/*.png` (имена из характеристик, напр. `img_exp_animals_02_TL-pos_TR-thr_BL-neu_BR-sad`, `word_exp_30w_target-threat_01`),
`stimuli.csv`, `stimuli_tiles.csv` / `stimuli_words.csv` (категории, оценки, метрики, зоны интереса в пикселях), `settings.json` (с seed).

## Допущения

* Группа изображения берётся из CSV, из начала имени файла (`animals_03.jpg`) или назначается вручную.
* В экспериментальных словесных стимулах по умолчанию дистракторы — только из категорий, отличных от категории целевого слова.
