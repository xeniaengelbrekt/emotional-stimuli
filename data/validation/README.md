# Данные массовой валидации картинок

Здесь лежат только **оценки и служебные файлы**, сами фото в репозитории не хранятся (≈230 МБ, это ваш материал).

| Файл | Что это |
|---|---|
| `photos_ratings_updated_all.csv` | Средние оценки по каждой картинке по **всем** ответам (276 респондентов, 16 опросов). Столбец `файл` — уникальное имя картинки. |
| `photos_ratings_updated_filtered.csv` | То же без 39 респондентов с низким согласием с остальными (см. `respondent_quality.csv`). |
| `respondent_quality.csv` | Анонимная проверка качества ответов респондентов. |
| `form_urls.txt` | Публичные ссылки на 16 форм: из них скачиваются сами картинки. |

## Как заново получить картинки
```
node tools/fetch_form_structures.mjs output/forms $(cat data/validation/form_urls.txt)   # структуры форм (нужен playwright)
python3 -I tools/download_form_photos.py output/forms data/validation/photos_ratings_updated_all.csv output/form_photos/all
```
Имена файлов берутся из столбца `файл` таблицы (порядок картинок в форме = столбец `фото_в_опросе`). Если картинку в форме заменят или удалят, скачивание изменится — на всякий случай храните копию папки с фото у себя (диск/архив).

## Как пересобрать оценки из выгрузок ответов
```
python3 -I tools/build_validation_ratings.py <папка с выгрузками Яндекс Форм> <старая таблица> <папка результата>
```
