Стимулы для оценки когнитивных функций

Четыре методики: плоскостное ментальное вращение, вербальное мышление (филворд), определение различий и траектории (прослеживание чисел взглядом по мотивам теста Кинга — Дэвика). Для каждой — генератор PNG-стимулов; по умолчанию размер 1920×1080, его можно изменить.

Вместе со стимулами в ZIP-архив попадают инструкции для участника в виде PNG (что делать и какие клавиши нажимать), таблицы с описанием стимулов и зонами интереса и файл настроек. Каждый стимул получает уникальное английское имя, собранное из его характеристик.

Все вычисления выполняются локально в браузере. Загруженные списки слов никуда не передаются.

Создание стимулов

Выберите методику

01↻

Плоскостное ментальное вращение

Фигура-задание и четыре варианта ответа: какая получится после поворота на 90° по часовой, против часовой, на 180° или после зеркального отражения. Ч/б и цветные варианты, оценка салиентности.

Ответ — цифра 1–4 на клавиатуре

→
02Аб

Вербальное мышление (филворд)

Сетка букв и цифр со спрятанными целевыми словами из вашего CSV. Размер сетки, цветность, число слов, направление, подбор слов по длине, частотности и эмоциональной категории.

Ответ — щелчок мыши по слову

→
03≠

Определение различий

Серия экранов: сначала N объектов нужно запомнить, на каждом следующем экране один объект меняется — на него нужно нажать. Буквы или числа, сетка или хаотичное расположение.

Ответ — щелчок мыши по изменившемуся объекту

→
04⋯

Траектории

Числа в несколько строк; нужно проследить их взглядом по возрастанию или убыванию, не называя и не нажимая, и оценить себя от 1 до 5. Дистракторы, прямое и зигзагообразное расположение, настройка каждого стимула.

Оценка — цифра 1–5 на клавиатуре

Анализ движений глаз и ответов в разработке
