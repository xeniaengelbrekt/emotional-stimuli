# Что передать в другие продукты: когнитивные стимулы и интервью (с голосом)

Источник: репозиторий `xeniaengelbrekt/emotional-stimuli` (ветка `claude/focused-edison-t5kdd1`).
Справка по методологии анализа — в приложении («Помощь» → «Анализ: …», файл `js/help.js`).

## 1. Платформа и дизайн (брать как есть)

- Тема: `css/style.css` (из «Салиентности») + `css/app.css` (поля форм, подсказки, оповещения, галерея, окно просмотра).
- Структура: статический сайт на ES-модулях, без сборки и серверной части; запуск `python3 -m http.server`.
- Главная с карточками «модуль → задача», у каждого модуля пометка «в разработке» там, где не готово; справка в окне с вкладками.
- Всё считается локально в браузере, файлы никуда не передаются (важно для персональных данных).

## 2. Общий код (`js/common`, `js/core`)

| Модуль | Зачем |
|---|---|
| `common/rng.js` | воспроизводимый генератор (seed), перестановки |
| `common/csv.js` | разбор CSV (`;` `,` TAB, десятичная запятая, русские/английские заголовки), запись CSV с BOM для Excel |
| `common/zip.js` | ZIP без зависимостей |
| `common/instruction.js` | инструкция участника как PNG того же размера, что стимулы |
| `common/ui.js` | dropzone, скачивание, окно просмотра, средняя яркость |
| `common/emotions.js` | эмоциональные категории по оценкам (с порогом и z-оценками) |
| `core/stats.js` | ANOVA, t, p-значения, доверительные интервалы |
| `core/toast.js` | уведомления |

## 3. Принципы генераторов (повторить в новом продукте)

1. **Воспроизводимость:** «номер случайного набора» сохраняется в `settings.json`.
2. **Подбор несколько раз (best-of-N)** и выбор лучшего по балансу условий.
3. **Проверка выполнимости до запуска:** таблица «доступно / нужно», понятное предупреждение, режим «повторы разрешены», сборка максимума возможного.
4. **Баланс-отчёт** с ANOVA по условиям (чтобы условия не различались по постороннему признаку).
5. **Выравнивание положений** по набору (категория или цель не должна всегда стоять в одном месте).
6. **Имена файлов из характеристик** (латиница, уникальные): `img_exp_animals_02_TL-pos_TR-thr_BL-neu_BR-sad`.
7. **Архив:** PNG, `instruction.png`, таблицы стимулов с координатами областей интереса, `settings.json`, яркость стимулов (для зрачка).
8. Все подписи настроек — понятным русским языком, под неочевидными полями серые подсказки.

## 4. Методология анализа (общая часть)

- Смешанные модели (участник и стимул как случайные эффекты), тип модели по типу показателя (см. справку «Анализ: схема»).
- Три уровня метрик (главные, вторичные, исследовательские) и счётчик проверок с поправкой.
- Малые выборки (25 + 25): анализ чувствительности, размеры эффекта с доверительными интервалами, байесовские факторы для нулевых результатов, мультиверс-анализ.
- Отчёт по APA на русском: методы, таблицы, графики (PNG и SVG), результаты шаблонным текстом.
- Зрачок (базовая линия, моргания, яркость как поправка) и моргания; энтропия по областям; ScanMatch и MultiMatch.

## 5. Что добавить для когнитивных стимулов

- **Задачи:** уточнить список (Струп, go/no-go, N-back, поиск и т. п.), для каждой — какие условия «контроль / эксперимент» и что считать ответом.
- **Баланс условий:** уравновешивание порядка (латинский квадрат), число проб на условие, тренировочные пробы, контрольные (catch) пробы.
- **Показатели:** время реакции (логарифм или ex-Gaussian), верность (логистическая смешанная модель), компромисс «скорость–точность», эффекты тренировки и усталости по номеру пробы.
- **Время предъявления:** привязка к кадрам монитора (60 Гц), метки событий для синхронизации с айтрекером 500 Гц (общее время или метка на входе).
- **Зрачок** здесь удобно использовать как показатель когнитивной нагрузки (не только возбуждения): требует постоянной яркости стимулов и фиксации базовой линии.

## 6. Что добавить для интервью с голосом

**Запись:**
- формат без потерь (WAV 44,1/48 кГц, 16–24 бит), один и тот же микрофон и расстояние (около 15–30 см), тихая комната;
- метка начала записи, общая с айтрекером (например, звуковой сигнал или метка в записи), чтобы выровнять голос и взгляд во времени.

**Акустические показатели** (минимальный стандартный набор eGeMAPS, 88 признаков, openSMILE):
- основной тон (F0: среднее, разброс, диапазон), интенсивность;
- джиттер, шиммер, отношение гармоник к шуму (HNR), форманты;
- темп речи, число и длительность пауз;
- MFCC и спектральные характеристики.
В браузере готовых аналогов openSMILE нет: возможны JS-библиотеки (Meyda, YIN-оценка F0) для части признаков; джиттер и шиммер придётся реализовать самим либо считать вне браузера. Нужно решить, что обязательно.

**Содержание речи:** расшифровка (локальная модель распознавания типа Whisper, чтобы запись не уходила в облако), эмоциональная лексика (русские словари тональности), латентность ответа.

**Организация интервью:** единый протокол, одинаковый порядок или уравновешенный порядок вопросов, фиксированная инструкция.

**Данные и право:** голос — биометрические персональные данные (в России 152-ФЗ): информированное согласие, обезличивание, хранение, удаление. Локальная обработка в браузере соответствует этому и должна сохраниться.
